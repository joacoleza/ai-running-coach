    **3. WeightProgressionChart.tsx**

    Props interface:
    ```typescript
    interface WeightProgressionChartProps {
      exerciseOptions: string[]   // unique sorted exercise names from gym sessions
    }
    ```

    Internal state:
    ```typescript
    const [selectedExercise, setSelectedExercise] = useState<string>('')
    const [chartData, setChartData] = useState<Array<{ date: string; maxWeight: number; unit: string }>>([])
    const [isLoading, setIsLoading] = useState(false)
    ```

    Exercise dropdown (above chart):
    ```tsx
    <select
      value={selectedExercise}
      onChange={(e) => handleExerciseSelect(e.target.value)}
      className="text-sm border border-gray-300 rounded-md px-2 py-1 text-gray-700 cursor-pointer"
    >
      <option value="">Select exercise</option>
      {exerciseOptions.map(name => (
        <option key={name} value={name}>{name}</option>
      ))}
    </select>
    ```

    handleExerciseSelect(name: string):
    - If name is empty, clear chartData and return
    - setSelectedExercise(name), setIsLoading(true)
    - `const res = await fetch('/api/runs/exercise-weights?exercise=' + encodeURIComponent(name), { headers: { 'X-Authorization': 'Bearer ' + (localStorage.getItem('access_token') ?? '') } })`
    - On success: const { data } = await res.json(); setChartData(data)
    - On any error (catch or res.ok=false): setChartData([])
    - finally: setIsLoading(false)

    Loading state: `<p className="text-gray-500 text-sm text-center py-12">Loading...</p>` inside 300px container

    Chart (when selectedExercise set and not loading and chartData.length > 0):
    Recharts LineChart with:
    - `<ResponsiveContainer width="100%" height={300}>`
    - XAxis: `dataKey="date"` tick `fontSize: 12`
    - YAxis: tick `fontSize: 12`, label `{ value: 'kg', angle: -90, position: 'insideLeft' }`
    - Tooltip: formatter `(v) => [${Number(v)}kg, 'Max Weight']`
    - Line: `type="monotone" dataKey="maxWeight" stroke="#3b82f6" strokeWidth={2} dot={{ r: 4, fill: '#3b82f6' }} activeDot={{ r: 6 }}`

    Empty state when selectedExercise is set but chartData is empty (and not loading):
    `<p className="text-gray-500 text-sm text-center py-12">No weight data for {selectedExercise}</p>`

    Empty state when no exercise selected:
    `<p className="text-gray-500 text-sm text-center py-12">Select an exercise to see weight progression</p>`

    Entire component fallback (exerciseOptions is empty):
    `<p className="text-gray-500 text-sm text-center py-4">Log a gym session with exercises to see weight progression</p>`

    Outer container: `<div className="bg-white border border-gray-200 rounded-lg p-4">`

    Export: `export function WeightProgressionChart({ exerciseOptions }: WeightProgressionChartProps)`
