## Component Inventory

### New Components

**1. DisciplineSelector**
- Type: Filter control
- Location: Dashboard.tsx top section (below title, above stat cards)
- Appearance: Horizontal button group (All/Run/Gym/Cycle)
- Active state: Gray-200 background, gray-900 bold text
- Inactive state: Gray-300 border, gray-600 text, hover gray-100
- Spacing: 8px gap between buttons, 24px below heading
- Behavior: Click updates `activeDiscipline` state, re-renders all cards + charts

**2. StatCard (discipline-aware)**
- Type: Data card
- Location: Grid below discipline selector (2 cols on mobile, 4 cols on desktop)
- Appearance: White bg, gray-200 border, 16px padding, 4px rounded
- Title: 12px, weight-500, gray-600
- Value: 24px, weight-700, gray-900
- Subtext: 12px, weight-400, gray-500 (for adherence progress)
- Discipline switching: When discipline changes, card titles/values update without layout shift
- Stat definitions:
  - **All**: Total Distance, Total Sessions, Total Time, (Plan Adherence if current-plan)
  - **Run**: Total Distance, Total Runs, Total Time, (Plan Adherence if current-plan)
  - **Gym**: Total Sessions, Total Duration, (blank 3rd card), (Plan Adherence if current-plan)
  - **Cycle**: Total Distance, Total Speed (avg), Total Time, (Plan Adherence if current-plan)

**3. WeeklyVolumeChart (multi-discipline)**
- Type: Recharts ComposedChart
- Location: Left card in 1–2 column grid (full width on mobile)
- Data: Aggregates all disciplines per week
- Visual: Stacked or grouped bars by discipline (run=blue, gym=orange, cycle=green)
- X-axis: Week label (e.g., "Apr 7")
- Y-axis: Volume (distance km for run/cycle, sessions count for gym)
- Tooltip: Shows discipline breakdown per week
- Empty state: "No sessions yet" centered in 300px height
- Title: "Weekly Volume"
- Note: Chart must display all three disciplines simultaneously when "All" is selected

**4. WeightProgressionChart (gym-specific)**
- Type: Recharts LineChart
- Location: Right card in 1–2 column grid (or below WeeklyVolumeChart on mobile)
- Appearance: White bg, gray-200 border, 16px padding, 4px rounded
- Control: Dropdown menu above chart showing exercise names (sorted alphabetically)
- Data: Max weight per session for selected exercise
- X-axis: Session date (MM-DD format)
- Y-axis: Weight (kg or lbs based on user preference — Phase 19 concern; for now assume kg)
- Line color: Blue-600 (#3b82f6)
- Dots: 4px radius, blue fill on hover, 6px radius
- Empty state: "No gym sessions with weight data" or "Select an exercise" (centered, 300px height)
- Title: "Weight Progression"
- Visibility: Only shown if user has logged gym sessions with exercise weights
- Fallback (no gym data): Hide chart entirely, show message "Log a gym session with exercises to see weight progression"

## Interaction Patterns

### Discipline Selector
- Clicking a button immediately updates `activeDiscipline` state
- All stats, charts, and cards re-render with discipline-scoped data
- Active button maintains focus/hover state for accessibility
- Mobile: Buttons wrap if needed (gap-2 = 8px between rows)
- No animation on state change

### Stat Cards
- Static layout (no hover state)
- Display strikethrough or "—" for unavailable metrics (e.g., pace when viewing gym)
- Adherence card clickable only when filter === 'current-plan' (existing behavior)

### WeeklyVolumeChart
- X-axis: Week labels clickable to navigate to Activities page filtered by that week (future enhancement, not required)
- Tooltip on hover: Shows exact values per discipline
- ResponsiveContainer: 100% width, 300px height
- Y-axis adapts label based on selected discipline:
  - All/Run: "Distance (km)"
  - Gym: "Sessions"
  - Cycle: "Distance (km)"

### WeightProgressionChart
- Exercise selector dropdown: Default value "Select exercise" (placeholder)
- Dropdown onChange: Re-fetches chart data for selected exercise
- Loading state: Three animated dots (existing pattern from ChatHistory)
- Line chart: Monotone interpolation, no fill
- Tooltip: "Date: MM-DD, Max Weight: X kg"

## Responsive Behavior

- **Filter buttons:** Wrap at 600px (gap-2 between rows)
- **Stat cards:** 2 cols (mobile), 4 cols (md+)
- **Charts grid:** 1 col (mobile), 2 cols (md+)
- **Chart height:** Fixed 300px for consistency
- **Chart tooltip:** Mobile: larger tap target, 16px padding

## Accessibility

- Discipline selector buttons: `aria-pressed` or semantic `<button>` (active = aria-selected)
- Stat card labels: `<p class="text-xs font-medium text-gray-600">` (visible label)
- Chart titles: `<h2 class="text-lg font-semibold">` (semantic heading)
- Empty states: Centered text, clear next-step instruction
- Tooltip: Native recharts behavior (mouse hover only, no keyboard access — acceptable for charts)
