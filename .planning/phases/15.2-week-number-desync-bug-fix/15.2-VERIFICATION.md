# Phase 15.2: Week Number Desync Bug Fix — Verification Report

**Phase Goal:** When a week is deleted from or added to a phase, `assignPlanStructure` renumbers plan week numbers but the `runs` collection is not updated — causing ghost-completed plan weeks with no linked runs and duplicate run links on the wrong week. Fix both `deleteLastWeekOfPhase` and `addWeekToPhase` to bulk-update `runs.weekNumber` after renumbering.
