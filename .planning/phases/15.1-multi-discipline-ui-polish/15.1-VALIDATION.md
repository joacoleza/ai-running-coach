## Gaps Found

Before this validation pass, the following requirements had no automated test coverage:

1. **ExerciseList component** — No test file existed. The component was only exercised through a mock in RunDetailModal tests. The real behaviours (warn at 15, block at 20, Remove with confirm, add flow, no standalone Save button) were untested.
2. **`fetchUnlinkedRuns` discipline param** — The existing useRuns.test.ts tested the function but not the optional second argument that constructs `&discipline=...` in the URL.
3. **RunDetailModal RunBadge in header** — No test verified that the discipline badge appeared in the modal header for each discipline type.
4. **RunDetailModal gym field hiding** — No test verified that Distance and Pace fields were absent for gym sessions.
5. **RunDetailModal gym feedback message** — No test verified that the `handleAddFeedback` prompt for gym sessions included session type and exercise count.
6. **DayRow discipline badge** — No test verified that RunBadge rendered for gym/cycle plan days, or was absent when discipline was not set.
7. **DayRow "Link session" button** — No test verified the button label, its conditional rendering based on `onRunLinked` prop, or its click handler.
8. **LinkRunModal dayDiscipline prop** — No test verified that `fetchUnlinkedRuns` was called with the `dayDiscipline` value, or that the discipline-aware empty state rendered.
