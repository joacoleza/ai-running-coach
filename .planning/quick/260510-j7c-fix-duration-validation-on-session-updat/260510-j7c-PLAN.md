  <action>
    In api/src/functions/runs.ts:

    1. Extract the duration validation logic into a module-level helper immediately below
       computePace():

       ```typescript
       function isValidDuration(duration: string): boolean {
         return /^\d{1,2}:\d{2}$/.test(duration) || /^\d{1,3}:\d{2}:\d{2}$/.test(duration);
       }
       ```

       This is the same regex used in RunEntryForm.tsx — strict MM:SS or HH:MM:SS, no trailing
       characters (regex anchors `^` and `$` prevent "12:0011" from passing).

    2. In the PATCH handler (updateRun), after body is parsed and before the DB query, add:

       ```typescript
       if (body.duration !== undefined && !isValidDuration(body.duration)) {
         return { status: 400, jsonBody: { error: 'Invalid duration format. Use MM:SS or HH:MM:SS.' } };
       }
       ```

       Place this guard after the JSON parse block and before the `getDb()` call (no DB round-trip
       wasted on invalid input).

    3. Also call isValidDuration in POST /api/runs (createRun) for the same protection. Add the
       same guard after the required-field check:

       ```typescript
       if (!isValidDuration(duration)) {
         return { status: 400, jsonBody: { error: 'Invalid duration format. Use MM:SS or HH:MM:SS.' } };
       }
       ```

    Add a new describe block `PATCH /api/runs/:id - duration validation` with the 6 test cases
    from the behavior section. Use the existing `makePatchReq` helper and `handlers.get('updateRun')`.
    Insert a run document in beforeEach (or inline) via mongoClient to have a valid ID to PATCH.

      await page.route('**/api/runs**', async (route: any) => {
        const url = route.request().url()
        if (url.includes('/run-edit-001')) {
          await route.fulfill({ contentType: 'application/json', body: JSON.stringify(testRun) })
        } else {
          await route.fulfill({ contentType: 'application/json',
            body: JSON.stringify({ runs: [testRun], total: 1, totalAll: 1 }) })
        }
      })

      // Navigate to Activities and open the run detail modal
